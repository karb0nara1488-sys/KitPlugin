# KitPlugin

Плагин наборов предметов для Minecraft на Paper 1.21.x.

## Возможности
- `/kit` для открытия GUI с наборами
- `/kit <название>` для получения набора
- 5 готовых наборов: Starter, Miner, Warrior, Archer, Farmer
- Настраиваемые предметы, названия, описания и кулдауны
- Система разрешений для каждого набора
- `kit.admin` для обхода прав и кулдаунов
- Сохранение кулдаунов после перезапуска сервера
- Защита GUI от перемещения предметов

## Требования
- Java 21
- Paper 1.21.x

## Установка
1. Скачайте JAR-файл.
2. Поместите его в папку `plugins`.
3. Перезапустите сервер.
4. Настройте наборы в `plugins/KitPlugin/config.yml`.

## Команды
- `/kit` открывает меню наборов.
- `/kit <название>` выдаёт выбранный набор.
